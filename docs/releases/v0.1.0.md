## RiskCheck v0.1.0

首个开源版本，采用 MIT 许可证。面向运维与 CI，对 2026 年 10 月安全事件进行离线版本和证据检查。

### 能力

- 23 条专项规则，核实日期 2026-10-22；涉及 Node.js、PHP、nginx、Tomcat、Go、Rust 证书依赖与 LiteLLM 事件。
- 读取项目文件及显式资产清单，区分版本命中、静态线索、厂商回补声明与历史暴露。
- 文本 / JSON / 离线 HTML；退出码 0 为范围内通过、1 为风险阻断、2 为证据不足或错误。
- 不联网、不安装目标依赖、不执行目标代码；只用 Python 3.9+ 标准库。
- 39 项行为与分发测试，标准安装包、跨系统 CI、文档及社区贡献入口。

### 下载选择

- 推荐 `riskcheck-0.1.0.pyz`：便携版，自带规则，无需 pip 安装。
- `riskcheck_offline-0.1.0-py3-none-any.whl`：在干净虚拟环境中离线安装。
- `riskcheck-0.1.0-source.zip` / `riskcheck_offline-0.1.0.tar.gz`：源码与开发。
- `SHA256SUMS`：逐项核对附件的完整 SHA-256 摘要。

```sh
python3 -I -S riskcheck-0.1.0.pyz --version
python3 -I -S riskcheck-0.1.0.pyz --root /srv/project --inventory assets.json --format json
```

[完整安装与部署步骤](https://github.com/MoFanMon/riskcheck/blob/v0.1.0/docs/deployment.md)

### 范围

这是有日期的事件规则快照，默认 30 天后要求复核。版本命中不等于已被利用，静态线索不等于攻击可达，通过也不表示系统安全。首版不验证真实 TLS 链，不发现全部运行态资产，不替代事件响应。尚未发布到 PyPI 或 GHCR。
